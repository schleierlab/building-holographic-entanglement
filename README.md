# Code for "Building Holographic Entanglement by Measurement"

We introduce a graph-based protocol to build Gaussian states with
holographic entanglement structure matching a target geometry.
In our definition, a state with holographic entanglement structure
has entropies that obey the Ryu-Takayanagi formula for the chosen spatial
geometry.

> [!NOTE]
> Compared to a state, a holographic _system_ that evolves in time requires more stringent conditions
> to be holographic.
>  - Instead of just spatial symmetries, the full conformal group must be satisfied
>    for a holographic system that is extended over spacetime.
>  - Our work can be seen thus as capturing some of the properties of an equal-time snapshot
>    of a holographic system.

This repository demonstrates the use of Gaussian states and
measurement of a subset of modes to prepare states with
holographic entanglement structure on the remaining modes.

To do this, we first build a graph that discretizes the desired
geometry. The examples in the figure notebooks include:

* hyperbolic disk
  - This discretizes an equal-time slice of anti-de Sitter (AdS) space.
  - Currently, in the code the hyperbolic disk is also called a tree with crosslinks, which is how we construct the graph.
* wormhole
  - This discretizes an equal-time slice of a two-sided AdS black hole.
  - Its dual is the thermofield double state of two CFTs.
* decorated graphs and regular hyperbolic patches
  - These are used in the supplemental figures to test how robust the entanglement structure is across graph choices.

## Quick Start

Run `01_introduction.ipynb` to generate figure 1, which in part shows entanglement entropy for various region sizes on the
boundary of the discretized hyperbolic disk.

To regenerate figures from the command line, run for example
`python scripts/regenerate_figures.py 01` or `python scripts/regenerate_figures.py S01`.
To see which files would run without executing notebooks, use
`python scripts/regenerate_figures.py --dry-run`.

## Method

### Quench-And-Measure

Start with a graph that discretizes a geometry. Collect a set of Gaussian modes with
a number of modes equal to the number of nodes in the graph.  The modes may be initially squeezed
by some amount $\mu$ (typically $\mu < 1$).  Next, evolve the system under an interaction Hamiltonian
(a sum of $X_i X_j$ interactions) whose couplings are based on the edges in the graph.
Measure some of the modes (with projective homodyne measurements in the $P$ basis) to change the
entanglement structure on the remaining modes.

### Characterizing Entanglement Structure

We characterize the final entanglement primarily through entanglement entropies,
but we also sometimes look at Rényi entropies for various Rényi indices $\alpha$.

> [!IMPORTANT]
> Because all states and operations are Gaussian, we can efficiently calculate the quench-and-measure process
> as well as the entropies at the end through manipulations of the covariances, which form a matrix.

We find that the entanglement entropies numerically match
Ryu-Takayanagi predictions based on minimal surfaces within certain geometries whose discretizations we test.


## Installation

You definitely need `networkx` (preferably `pygraphviz` for additional visualization as well) and `numpy` and `matplotlib` to run this code.
The notebook and figure-generation workflow also uses `scipy`, `tqdm`, `pydantic`, `mpmath`, `nbconvert`, and `nbformat`.

The code was tested using:

- Python 3.13.3
- NetworkX 3.4.2
- Matplotlib 3.10.1
- NumPy 2.2.4
- SciPy 1.15.2
- mpmath 1.3.0
- tqdm 4.67.1
- pydantic 2.11.7
- nbconvert 7.16.6
- nbformat 5.10.4
- pygraphviz 1.14
- hypertiling 1.5.1

Depending on what modules you are using, you will want to install the above packages.

## Project Structure

- The top level contains notebooks for the main text figures.
  - `##_figure_description.ipynb`: generates a main text figure.
- `supplementary-notebooks` contains notebooks for the supplemental figures.
  - `S##_figure_description.ipynb`: generates a supplemental figure.
- `graph2grav`: contains the main codebase.
- `figure_helpers`: contains helper functions specific to the figure notebooks.
- `figures`: contains figures generated by figure notebooks.

## Tips

- If you are running into invalid symplectic eigenvalue issues (e.g. warnings that symplectic
  eigenvalues are too small), assuming everything else is fine, you probably are in an extreme or unphysical regime and should dial back some parameters.
